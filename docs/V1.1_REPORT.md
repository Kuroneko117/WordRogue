## Completed / UI Changes

保留全部 V1 核心功能：120 个词、四选一、HP、Combo、四场路线、三次奖励、六件强化、Mastery、弱词加权、存档、胜败报告与重开。

结算原逻辑无误：不同单词数与答题次数不是同一指标。V1.1 用本局统计显示 Questions Answered、Unique Words、Correct、Wrong、Accuracy、Best Combo。统计不读取全局累计次数。

战斗界面改为顶部区域/进度、左右角色、中央 Word Spell 和四个选项、底部攻击/Combo/答题次数。战斗主体由 MarginContainer、VBoxContainer、HBoxContainer、GridContainer 排列，采用 16:9 等比缩放。青蓝学徒、紫红敌人、金色卡片和程序图书馆保留 Dark Academia 方向。奖励保留三卡布局，新增与强化对应的图标、悬停边框和选择高亮。

ESC 使用 SceneTree 原生暂停。暂停菜单独立设置 Always 处理模式，支持继续、重开、返回标题、退出；离开或重开均显示二次确认。标题与报告同样能够安全打开菜单。

## Animation System

正确答案：锁定按钮并结算一次 → 卡片发光、施法前移 → 青蓝魔法弹带拖尾飞向敌人 → 命中闪亮、后退震动 → 飘字和 HP 平滑变化 → 下一题。常规答对演出约 0.9 秒。

错误答案：错误红色、正确绿色与中文释义 → 敌人紫红反击 → 玩家受击/护盾飘字 → Combo 缩小归零；正确释义保留约 1.8 秒。待机采用轻微浮动与呼吸，独立攻击 pose 避免位移累加。

Combo 在 3、5、8 与之后每四次里程碑强调；5+ 青金色，8+ 短暂 UNSTOPPABLE。角色死亡收缩并渐隐，随后奖励或报告。精英与 Boss 使用独立入场提示、色彩强调；Boss 更大、血条更粗。

作答仅在 WAITING 状态受理。显式区分结算、动画、敌死、玩家死和结束。Tween 与延时均遵循暂停；切屏取消所有演出 Tween，并用递增 screen_epoch 阻止旧异步回调修改新页面。

## Weak Words / Boss

新增本局真实 `wrong_words` 记录，重开时清除，长期 Mastery 不变。Boss 在可用错词中以 70% 优先抽取；其他题优先低 Mastery，薄弱数据不足时退化到合理题池。最近三题被排除，避免连续重复。

`FORGOTTEN THIS RUN` 只用于本局真实错词；`WEAK WORD` 只用于 Mastery < 50。Boss 入场只有确实存在错词时才列出词汇。无错题时显示一般性的弱词挑战提示。

## Asset Integration

本轮没有正式 PNG 素材。已接好以下可选路径，缺失时使用原创程序绘制角色/背景，人物图保持宽高比：

`assets/characters/word_mage.png`

`assets/enemies/ink_wraith.png`, `dust_sentinel.png`, `marginalia.png`, `librarian.png`

`assets/backgrounds/library_battle.png`

`ActorView.art_scale`、`art_offset`、`modulate` 可调整缩放、位置和透明度。第二场 Dust Sentinel 是 V1 保留敌人，提供独立可选路径。素材放入工程后让 Godot 导入，再重启游戏。

## Audio

`AudioBus.play_event()` 支持十二种事件：ui_click、correct、wrong、player_cast、player_hit、enemy_hit、enemy_death、combo_trigger、reward_select、victory、defeat、boss_intro。

把对应同名 `.ogg` 或 `.wav` 放到 `assets/audio/sfx/`，Godot 导入后重启。缺失音效静默跳过。本轮未制作声音或音乐；`assets/audio/bgm/` 只预留目录。详细约定见 `assets/README.md`。
