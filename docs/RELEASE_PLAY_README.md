# 遗忘书塔 · WordRogue V1.9

Windows 64 位试玩版。解压整个目录，双击 **WordRogue.exe**。
`WordRogue.pck` 必须放在 exe 同一目录，不可单独移动 exe。

- 鼠标选择路线、法术和中文答案，也支持键盘 1–4 / QWE。
- ESC 打开暂停菜单，可调节音乐和音效。
- 触屏界面预览：命令行 `WordRogue.exe -- --touch-ui`；这不等于 Android 真机验证。
- 本地学习记录与音量保存在 `%APPDATA%\Godot\app_userdata\WordRogue Prototype V1`。
- 版本保持原有存档路径，试玩包不包含开发者/玩家存档。

音乐/音效说明见 AUDIO_LICENSES.md；字体使用 SIL OFL 1.1 的 Noto Sans SC。
