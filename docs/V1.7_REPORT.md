七类场景入口已接入原AudioBus。仍只有原normal_battle.ogg与boss_battle.ogg：

| 分类 | 首选文件 | 当前实际行为 |
| --- | --- | --- |
| title_map | title_map.ogg | 缺失，静音 |
| battle_normal | normal_battle.ogg | 原曲 |
| battle_elite | elite_battle.ogg | 缺失，回退原普通曲 |
| battle_boss | boss_battle.ogg | 原首领曲 |

| event_special | event_special.ogg | 同上 |
| optional_victory | victory_result.ogg | 可选缺失，淡出静音 |

需补四类必需专用BGM（标题地图、精英、书房、事件），另有可选胜利曲。没有把音乐说明板当成音频，没有下载或生成新曲。

单Music播放器串行淡出0.2秒→换流→淡入0.4秒；同物理曲目的安静/恢复改为0.25秒平滑调节；缺曲淡出0.25秒。普通与精英回退同曲不重新播放。书房/事件/地图按自己的分类选择，不再直接沿用上一场战斗曲。ESC继续暂停当前位置、独立BGM/SFX音量、0%静音、即时生效和自动保存。

每种怪物攻击有独立释放与命中事件；专用同名WAV/OGG优先，否则按 `AudioBus.MATERIAL_SOUNDS` 复用已有CC0音频和音调。当前是过渡复用，不宣称具有新录制的真实纸页、墨水、灵火或锁链音色。蓄力声音在蓄力开始，释放在效果出现，命中在原碰撞时刻；实际扣血才播玩家受击，护盾挡伤维持原事件。旧玩家法术、UI和音乐接口保留。

## 7. 文件职责

- `scripts/presentation_profiles.gd`：场景背景/音乐、未来立绘尺寸、26攻击显示配置。
- `scripts/ui/enemy_spell.gd`：墨、纸、火、链、书与法阵的轻量程序显示。
- `scripts/enemy_presentation.gd`：沿用原动画时序，读取显示配置并发送对应声音事件。
- `scripts/main.gd`：在清屏前选择正确场景背景/音乐，避免使用上一个screen状态。
- `scripts/audio_bus.gd`：音乐逻辑类别→实际资源回退、平滑同曲音量、材质音效回退。
- `scripts/ui/battle_view.gd`：未来PNG查找与等比尺寸；答案反馈底条。
- `scripts/ui/screen_base.gd`：仅更新标题V1.7版本文字。
- `assets/README.md` / `ASSET_CREDITS.md` / 根README：资源命名、缺失状态、原图来源与启动说明。
