## 地图

### 实际实现

- 从四层路线扩为 **十二层旅程、34 个节点**：入口、首战、第二至十一层各三节点、最终首领、学习报告。
- 采用由下向上探索的纵向滚动地图，以原创程序图标表示普通战、精英、回忆书房、休息书桌、藏宝书架和最终首领；没有使用或下载《杀戮尖塔》的图片。
- 暖金点线表示可走路径，绿色表示完成；跳过节点有斜线，未解锁节点暗化，首领为更大的冠冕骷髅图标。
- 每局随机排列同层节点类型，改变相邻连接。连接只前进一层，同列始终可走，可连接相邻列；没有死路或不可达节点。
- 每层只能选一个相连节点。进入时锁住其他节点，完成后禁止重访与重复收益。
- 提供滚轮/滚动条、查看塔顶、定位当前位置；初次显示和每次回图自动定位当前位置。
- 右侧图例、鼠标悬停收益、生命与本局遗物列表帮助选路。遗物名称和类别使用中文，可悬停查看效果；列表可滚动。

### 节点收益

| 节点 | 收益 / 风险 |
| --- | --- |
| 普通战 | 三选一强化一次；胜利恢复 5 生命 |
| 精英战 | 三选一强化连续两次；胜利恢复 8 生命；保留精英攻击和低掌握度加权 |
| 回忆书房 | 原三道复习；每次答对恢复 5 生命，有温习手稿时为 7；保留原掌握度更新 |
| 休息书桌 | 恢复最大生命 20%，向上取整并封顶；不增加答题或学习记录 |
| 藏宝书架 | 无战斗，直接选择一件遗物或补给 |
| 最终首领 | 第十二层必经；保留本局错词/长期弱词优先和第二阶段；胜败进入学习报告 |

普通/精英基础胜利回血可与治愈羽笔原 +10 叠加，不超过最大生命。为让长旅程中后期仍有战斗长度，敌人生命按 `原生命 + (所在层 - 1) × 14` 增长，原攻击力及攻击倍率未提高。首战仍为 50 生命，第十二层首领为 254 生命。

## 奖励与组合

奖励池从六件扩为 **18 件本局遗物 + 3 种可重复补给**。原六件保留原效果，新增内容如下：

| 类别 | 名称 | 实际效果 |
| --- | --- | --- |
| 法力 | 聚能指环 | 本局法力上限 3→4 |
| 法力 | 法力泉瓶 | 每场初始法力 1→2 |
| 进攻 | 余响铭文 | 奥术飞弹在正常伤害后额外 +3，不影响守护或爆发 |
| 进攻 | 专注透镜 | 3 连击及以上，正常伤害 +2 |
| 进攻 | 战前筹谋 | 每场首次答对，正常伤害 +6；答错不消耗机会 |
| 防御 | 符文护页 | 守护答对获得 10 护盾，护盾上限 16→20 |
| 防御 | 青金壁垒 | 每场开始获得 6 护盾 |
| 防御 | 反击墨镜 | 护盾确实吸收伤害且玩家存活时反伤 4；可以击杀敌人，死亡时不反伤 |
| 记忆 | 共鸣书签 | 记忆爆发对本局旧错词追加伤害 5→10；不伪造错误记录 |
| 记忆 | 温习手稿 | 书房答对的恢复量 5→7，不改变学习算法 |
| 续航 | 生命书签 | 本局最大生命 +15，立即恢复 15 |
| 续航 | 复苏墨水 | 每场首次达到 5 连击恢复 8，仅一次，可与记忆水晶同时触发 |
| 补给 | 生命药剂 | 立即恢复 20，生命封顶，可重复获得 |
| 补给 | 应急护符 | 下一场起始护盾 +8，可累积至本局护盾上限，进入该战斗后消耗 |
| 补给 | 灵感墨滴 | 下一场首次答对正常伤害 +8，可累积至 16；错误不消耗首次正确机会 |

- 每次提供三个不同选项；永久遗物不重复获得。未拥有遗物足够时至少两个遗物选项，第三个以 35% 概率替换成补给。
- 遗物不足三个时由补给填满，避免长局奖励池耗尽；补给不冒充永久遗物。
- 普通伤害先统一计算原 Combo、原强化和新增正常伤害加成，再应用法术倍率；余响和旧错词爆发追加分别处理，避免重复加算。
- 守护仍然 **全正常伤害 + 护盾，答错减伤 30%**；没有恢复之前的半伤害版本。
- 奖励卡加上颜色类别与程序图标，明确区分本局遗物和可重复补给；仍保留三卡选择、悬停和选择锁定。
- 重开重置最大生命、法力上限、遗物、补给与临时状态，保留长期学习数据。

可尝试：法力泉瓶 + 聚能指环的爆发组合；符文护页 + 青金壁垒 + 反击墨镜的防御组合；词锋之刃 + 专注透镜 + 连击之焰的连续进攻组合。随机奖励不保证凑齐全部组件。

## ESC 声音设置

- 暂停菜单新增“声音设置”，背景音乐与战斗/界面音效分别使用 0～100 滑块；0 为对应音频总线静音。
- 调整直接作用于原 BGM/SFX 总线，不修改音频文件或事件绑定、不重新开始音乐；包含试听界面音效、恢复默认、返回暂停菜单。
- 默认音乐 50%、音效 75%，接近升级前音量；显示百分比是设置量，不代表人耳感知响度的线性比例。
- 设置期间维持 Godot 原生暂停，战斗 Tween、延时和题目结算不推进。首次 ESC 返回暂停菜单，再按 ESC 恢复游戏。
- 自动保存到 **`user://wordrogue_audio.cfg`**，与 `user://wordrogue_save.json` 分开。首次运行无设置文件时使用默认；读取失败或值类型错误时安全恢复，数值限制在有效范围。
- 标题、地图、战斗与结算都能使用既有 ESC 菜单；重开、返回标题和退出的确认流程保留。

## 当前限制与人工验收

- **15～20 分钟是设计目标，尚未人工计时确认。** 最近模型旅程产生 68～94 次答题；实际阅读速度、正确率、法术与奖励选择会改变长度。
- 长局回血、怪物生命增长与奖励组合尚未经过多位玩家平衡测试。请记录具体路线、遗物、正确率和完成时间，作为下一轮调整依据。
- 音量总线和持久化已自动验证，舒适响度及长时间音色仍需耳机/音箱人工确认。
- 图标由程序绘制，可游玩但不是最终地图美术；当前保持原有角色与背景素材。

### 简短试玩清单

1. 重启游戏，开始冒险；滚动全塔、悬停图标、选择连接的不同路线。
2. 尝试一局进攻、一局防御或法力组合；检查遗物说明、护盾反伤和精英连续两次强化。
3. 进入书房、休息和藏宝，确认收益且不能重复领取。
4. 施法中按 ESC → 声音设置，分别调音量与静音；恢复后确认没有重复结算。
5. 结束/重开，确认本局强化清除、长期掌握度保留；重启确认音量保留。
6. 实际计时一局，记录是否接近 15～20 分钟、后期重复感和哪些组合过强/过弱。
