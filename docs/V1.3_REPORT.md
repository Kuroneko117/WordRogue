## 2. Completed / 法术规则

每场开始 **法力 1/3、护盾 0**；法力和护盾均不跨战斗继承。每题默认选中 Arcane Bolt，可自由切换，法力不足的技能禁用。只有提交有效答案时才消费法力；答错也消费相应技能费用。

| 法术 | 消耗 | 答对 | 答错 |
|---|---:|---|---|
| Arcane Bolt / 奥术飞弹 | 0 | 正常最终伤害；法力 +1，上限 3 | 不增加法力；敌人反击 |
| Aegis Seal / 守护咒文 | 1 | 正常最终伤害 ×50%；护盾 +8，上限 16 | 不获得护盾；敌人反击 |
| Memory Burst / 记忆爆发 | 2 | 正常最终伤害 ×180%；本局之前答错过的词额外 +5 | 无攻击效果；敌人反击 |

伤害先沿用原 Combo、Word Blade、Beginner's Tome、Combo Flame 的完整普通伤害计算，再只应用一次法术倍率，整数向上取整。额外的记忆 +5 在倍率后计算。例：正常伤害 30 → 飞弹 30、守护 15、记忆 54；旧错词记忆为 59。

敌人伤害先由护盾吸收，剩余扣 HP。Scholar Shield 首次免疫优先，不消耗已有护盾。Memory Crystal 连击里程碑回血、Healing Quill 战后回血保持原规则。新法术不会额外记录 Mastery 或重复增加统计。

记忆追加效果通过提交答案前的 `wrong_words.has(word)` 判断，仅认本局真实旧错词；长期 wrong_count 不会伪装成本局错误。

## 4. Animation System / 状态安全

- **奥术飞弹**：蓝金小光弹、拖尾、明确飞行轨迹、命中光环与星芒。
- **守护咒文**：金蓝椭圆符文屏障围绕玩家展开，旋转符文、`+8 SHIELD` 飘字；附带 0.7 倍视觉尺寸的小飞弹。护盾持续到消耗完，受击显示独立的 `SHIELD -n`。
- **记忆爆发**：约 0.30 秒蓄力环、1.65 倍投射物、1.5 倍命中爆发。真实旧错词触发独立 `MEMORY RESONANCE +5 · 本局旧错词`，下题恢复常规弱词色。
- **敌人反击**：紫墨弹与墨色碎片；Boss 使用深红变体。沿用原立绘 Attack / Hit / Idle / Death Tween。
- 通常答对约 0.9 秒，记忆约 1.05 秒；答错保留正确释义约 1.8 秒。0.30 秒投射物飞行结束时显示 HP 变化。
- 等待作答期间才允许选技能与答题；提交立即锁定，两次快速点击只结算一次。原暂停机制冻结 Tween、蓄力、符文绘制、延时与音频。
- 切屏销毁特效、取消已登记 Tween，并通过 screen_epoch 阻断旧回调；新增只停止 SFX 的 `stop_effects()`，避免重开时旧蓄力声溢出，同时保留 BGM 流程。
- 法术特效全部为 Godot 程序绘制与 Tween，没有新增外部贴图、插件或网络依赖。

## 5. Audio / 问题原因与修复

### V1.2 实际原因

1. `enemy_cast` 被绑定到 `player_cast.wav`，仅将 pitch_scale 降至 0.80。两方释放声实际是同一资源。
2. `enemy_hit` 被绑定到 `magic_hit.wav`，源为 JaggedStone 的 magical_5 魔法效果片段；没有独立区分投射物碰撞与怪物受伤。用通用魔法声表达生物受击语义不清。
3. 播放入口本身可用，并非缺少音频文件或全局静音；问题主要在素材选择和事件绑定。

核查使用原 WAV 解码、峰值/RMS/过零及周期相关性分析、源文件和绑定对照，没有声称完成主观人工试听。采用两组明确 CC0 的资源补充释放、物件碰撞和生物受伤声音；原玩家受击文件保留。

| 动画时刻 / 事件 | 实际资源 |
|---|---|
| 玩家释放 / player_cast | arcane_release.wav，独立轻挥动声 |
| 敌人释放 / enemy_cast | enemy_cast.wav，独立较重挥动声 |
| 普通碰撞 / projectile_impact | projectile_impact.wav，短物件冲击 |
| 怪物受伤 / enemy_hurt | enemy_hurt.wav，生物受伤片段 |
| 玩家 HP 受伤 / player_hit | 原 player_hurt.wav |
| 守护展开 / aegis_activate | aegis_activate.wav，短晶体音 |
| 护盾挡伤 / shield_hit | shield_hit.wav，短金属冲击 |
| 记忆蓄力 / memory_charge | memory_charge.wav，短魔法片段 |
| 记忆释放 / memory_burst | memory_burst.wav，独立挥动声 |
| 记忆碰撞 / burst_impact | burst_impact.wav，较强碎裂冲击 |

新增九个 WAV，旧 V1.2 音效未覆盖。处理包括裁去前导静音、短淡入淡出、单声道 PCM16 和限制峰值，时长约 0.10～0.35 秒。运行中额外降低碰撞、怪物受伤、爆发命中和蓄力音量，避免叠加过响。保留原 Master/SFX/BGM 参数、两首音乐文件及音乐切换逻辑。

释放声在投射物出现时触发，碰撞/受伤声在命中时触发；无 HP 损失不播放玩家受伤，有吸收伤害则播放护盾事件。每个对应事件只触发一次。`AudioBus` 仍支持缺少资源时静默跳过，并限制最多八个同时播放的短音效。

来源：artisticdude 的 [Swishes Sound Pack](https://opengameart.org/content/swishes-sound-pack) 和 rubberduck 的 [80 CC0 RPG SFX](https://opengameart.org/content/80-cc0-rpg-sfx)。逐文件原始来源、作者、CC0 许可和日期见 `docs/ASSET_CREDITS.md`；源声学测量与处理增益见 `assets/audio/v13_manifest.json`。

## 9. How to Run / Manual Review

用 Godot 4.7.2 打开 `D:\项目\1\project.godot`，按 F5；或运行：

```powershell
& 'D:\godot\Godot_v4.7.2-stable_win64.exe' --path 'D:\项目\1'
```

当前没有已知阻塞运行的问题。需要人工验收的部分：

1. 连续飞弹积攒法力，检查三技能名称、消耗与切换是否直观。
2. 选择守护答对，再故意答错，观察屏障、护盾先扣与 HP 差额。
3. 对本局曾错过的词使用记忆，检查蓄力、飞行、爆发和独立 +5 提示。
4. 戴耳机试听玩家/敌人施法、碰撞、怪物受伤、护盾和记忆音色，确认区别、音量和同步感；玩家受击沿用旧声。
5. 动画中 ESC，恢复、重开和返回标题；检查旧声音/特效是否停下。
6. 到精英/Boss、完成或失败后看报告；重启检查长期 Mastery 保留。

没有由真人逐题完成整局的主观验收；完整路线由实际 Godot 自动交互测试走通。不同屏幕/音频硬件、长时间体验和个人音色偏好仍需试玩反馈。OGV 播放取决于本机播放器支持，截图无需视频解码器即可查看。
