# 历史：全流程魔典 UI 方向与实施计划 · 2026-10-23

## 已授权方向

沿用用户指定的 `设定参考图/battle_ui_target.png` 与上一轮实际战斗古籍样式。用户要求覆盖全部流程并加强改造，本轮由工作室自主落实同一方向，无需重新选择画风。

观察来源：本地目标图、2026-10-22 的实机截图与已运行的主程序。参考图以古纸、旧金雕饰、深靛皮革、蓝金法术构成；上轮页面仍大量使用统一深色矩形，材质与场景语义不足。此判断来自当前画面，不以未核实竞品印象作依据。

## 方案

- 标题：魔典卷首与人物展示，主行动为翻开魔典；取消后台式大卡片感。
- 难度：三张试炼封印/竖向书页；推荐状态具有明确文字与徽记。
- 地图：星图/书塔路线盘，节点与连线为主，行囊为附页，保留全部路径和操作。
- 奖励：遗物藏页、独立徽记与品质刻印，三选一不变。
- 事件、书房、休息：故事书页/仪式台，正文、代价和行动区层次分明。
- 暂停与设置：魔典书签式菜单，设置像调音铭文页，滑条、静音、返回与危险操作确认清晰可操作。
- 结算：冒险日志双页，统计为页眉摘要，提升与弱词分栏；再来一局突出。
- 战斗：保持动态羊皮纸与原立绘，统一所有装饰、提示与状态。

## 共同规范

深靛 #0b121d，旧金 #c9ac76，纸色 #efe4cc，青蓝 #8abcc8，威胁 #d58785。标题用现有宋体/衬线与中文回退，正文保留已打包中文字体；数值和拉丁单词避免中文字库行高。文字全部由原生 Godot 控件渲染。

绘制语汇：真实纸张/深蓝皮革纹理、细金雕花、书脊/卷页、切角铭牌、法阵、章节刻度。装饰不拦截输入。普通、悬停、聚焦、按压、选中、禁用、危险确认、正确/错误均有可见反馈。缩放动效120–180ms，暂停遵循原状态机。

## 工程分工与顺序

1. 主代理：备份、开发分支、共享 Theme/表面/按钮、素材来源、战斗与统一装饰、最终整合。
2. Journal 工程师：仅标题/难度/奖励/休息/报告页面和其独立组件。
3. 流程工程师：仅暂停设置/事件/书房/地图页面和其独立组件。
4. 独立视觉 QA：只写审查证据和报告，不修改工程师代码。

验收：1280×720、1920×1080 全流程实际截图；长文本、空行囊、禁用、暂停设置、胜败日志；一次相关完整流程回归。源工程与真实存档保护，发行包不覆盖。记录美术差距，不把功能测试计数当作视觉质量结论。
