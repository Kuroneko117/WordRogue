### 限定结论

**VISUAL PASS：本轮已实际审看的 Windows 桌面1280×720与1920×1080全流程视觉布局。** 包括卷首、三试炼、路线图、战斗HUD与三法术槽、三选一藏页、事件选择与禁用、事件词汇题、书房、休息、暂停、声音设置、危险确认、空数据日志及修复后的长词日志布局。质感与层级相对旧版明显改善，已无本轮发现的主要遮挡或操作出屏问题。

以下不属于通过范围：

- `report_long_lists` / `report_scrolled` 是人为8条重复长词UI压力夹具，0/7层及0答题等统计不可用来证明真实通关。`hero_cast_*`原有1000HP压力夹具同理。
- 已读测试对两个ScrollContainer设置 `scroll_vertical=100` 并断言实际滚动；已看滚动前后图。它证明程序滚动可用，**未证明人工鼠标滚轮/键盘能遍历到第8条末项**，该导航仍建议人工复验。不得把截图解释成全部条目已逐项检查。
- 主工程师完整回归曾1803断言/2失败，失败定位为report_win操作出屏，之后本轮定向456/0复验通过。不能把这个过程合并叙述为“整轮从未失败”。
- 本审核员不以截图代替功能测试、音量设置保存、战斗时序、存档完整性或性能剖析；这些由主报告独立列实际证据。
- 未测试移动真机、微信小游戏生命周期、触控安全区、包体/发布审核，也没有发布资格判断。
