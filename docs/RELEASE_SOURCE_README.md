# WordRogue V1.9 精简运行工程

使用 Godot 4.7.2 打开 project.godot，首次导入后运行。包含现有游戏代码、两套词库、正式立绘、六首音乐、音效、中文/音标字体；不包含玩家存档、历史备份、参考图、录像、测试或编辑器缓存。

源 PNG/JPG 与原工程一致；`.import` 保留发布用 WebP 导入参数（质量 0.82，角色最长边 1024、敌人 768、背景 1280）。字体按现有文字准备；未来加字需要更新字体子集。音乐没有重新编码。

Windows 导出预设的自定义模板路径为开发机器本地路径。换电脑后将其改为本机官方 4.7.2 Windows Release 模板，或清空自定义路径并安装对应官方模板。Android 预设仍需要 JDK17、Android SDK、Android 模板和发布签名，当前没有 APK。

所有存档路径与旧版一致。请保留目录中的音频、词库、字体、Godot 许可证与版权说明。
