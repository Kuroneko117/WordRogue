104 个原美术、音频、字体和词库文件的 SHA256 校验均未改变；13 个核心玩法/学习/路线/音频脚本与备份一致；真实 `wordrogue_save.json` 与 `wordrogue_audio.cfg` 哈希一致。测试使用 `.local_test/ui_pass_profile`，不使用真实学习存档。

## 3 统一视觉系统

采用“墨金藏书”：深靛墨背景、羊皮纸文字、旧金细框，蓝色代表玩家，暗红代表威胁。加入书脊、双层装订线、四角金属刻线、藏书封印和横向纸页刻线，不添加全屏发光或玻璃特效。

统一 Theme 在 `ui_kit.gd` 创建并通过主 Control 和暂停面板继承。正文保持现有打包 Noto 字体；中文标题优先使用系统宋体/衬线字体，英文单词与统计数字优先使用 Georgia，并保留原中文字体回退。没有下载或分发额外字体。

- `ui_kit.gd`：Theme、标题与数字排版、章节标题、封印、封面/纸页与按钮样式工厂。
- `assets/ui/archive/icons`：19 个原创 SVG，合计 4775 字节；32×32、同一笔宽与旧金配色。返回、关闭、设置、音乐、音量、确认、生命、攻击、防御、法力、楼层、事件、奖励、书籍等。常见菜单图标已接入，其余预留为统一图形资源。
- `assets/ui/archive/manifest.json`：素材来源和预算记录。没有下载新 PNG，没有替换用户正式立绘或背景，没有更改 BGM。

## 6 动画与反馈

屏幕页面进入采用 0.22 秒淡入；按钮悬停/聚焦使用 0.13 秒轻微放大，按下压至 0.985，释放回弹。Tween 绑定实际控件并随节点销毁，不使用全局延迟写入新页面。

原施法蓄力→投射物→命中→伤害数字→血条、反击、死亡、Combo 与奖励选择反馈全部沿用既有时序。没有新增 hit stop 或改动战斗时间。切屏保留即时替换，避免为了离场演出延迟实际游戏输入。各页面入场动画不阻塞按钮。

## 7 可读性、性能与响应布局

角色与选项/血条的空间冲突由现有边界检查验证；施法特效仍在角色通道中，底部预告保持独立。高亮蓄势条与不可打断文字保留。装饰自绘在背景面板内，图标和文本装饰不吞鼠标；没有金币吸附或全屏粒子。

采用既有 1920×1080 参考画布、canvas_items 缩放、Margin/HBox/VBox/Grid 容器。修正造成高度外溢的字号度量与按钮内边距；没有将新界面改成一组绝对像素坐标。主要装饰只在 resize/状态变化时重绘，不每帧创建控件，不加实时后处理 Shader。尚未进行低端 GPU 性能基准测试，不以此宣称性能提高。
