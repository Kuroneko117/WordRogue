## 美术接入

用户提供的五个目标文件全部存在、可解码且已由 Godot 导入。四张角色图具有有效透明及半透明像素；正式图书馆背景正常显示。原始尺寸和 alpha 采样数据保存在 `.local_test/v12_final/asset_inspection.json`。

两场普通战共用 `ink_wraith.png`，第二场仍保留原 Dust Sentinel 名称与属性；第三场加载 `marginalia.png`；第四场加载 `librarian.png`。没有另行下载或生成角色。

1280×720 实测 PNG 包围高度：玩家普通/精英约 293px、Boss 场因宽图栏位约 263px；Ink Wraith 约 254px；Marginalia 约 295px；Librarian 约 327px。透明空白使可见人物略小于 PNG 包围尺寸。比例均等比，单词卡、四个选项及血条的边界检测通过。

Boss 原图较宽，使用更宽的右侧栏、较小的垂直留白及轻微上移取得目标尺寸，没有通过拉伸实现。图片方向保持原样。待机浮动、施法位移、受击闪亮与死亡渐隐继续作用于原 `visual → pose → art` 节点链。

背景采用 `TextureRect` 的 Cover 方式、忽略鼠标输入，叠加可调 30% 深蓝黑遮罩；正式背景存在时不再绘制旧程序书架与地板。缺图时仍回退到原背景/角色。用户原有 `assets/enemies/library_battle.png` 额外文件未删除，游戏只引用 `assets/backgrounds/library_battle.png`。

## 战斗特效

玩家蓝金魔法：短光迹、旋转金色符文环、青蓝核心；命中时金色星芒与小光点。普通/精英反击：紫墨能量与少量碎片。Boss：深红核心、暗金环及环绕书页，与普通反击可辨别。

全部使用 Godot 原生绘制与既有 Tween，无新技能、骨骼、复杂后处理或外部特效贴图。魔法弹约 0.30 秒飞行；常规答对演出约 0.9 秒，答错释义仍保留约 1.8 秒。命中效果约 0.42 秒自动释放。原状态锁、暂停和 screen_epoch 取消逻辑保留。

精英/Boss 入场、真实弱词标识和 Boss 本局错词提示保留；没有修改抽题算法或伪造错词。高 Combo 保留里程碑视觉与新增声音反馈。

## 音频

实际下载并集成十二个 CC0 音效：ui_click、correct、wrong、player_cast、magic_hit、player_hurt、enemy_death、combo、reward_select、boss_intro、victory、defeat。来源包括 Kenney Interface Sounds/RPG Audio/Music Jingles 和 JaggedStone Magic Spell SFX。

已用 Godot 原生 Vorbis 解码器离线裁剪、去前导静音、单声道 16-bit PCM、统一 RMS/峰值并添加短边缘淡入淡出。时长约 0.10～1.20 秒，解码峰值不超过约 0.62，没有强行加入刺耳爆炸或商业游戏声音。修改记录见 `assets/audio/audio_manifest.json`。

音乐：普通/精英使用 Ruhinre 的 **Whispers in the Fog**（15.36 秒），Boss 使用 SkyleTheFrench 的 **Dark Place (loop)**（54.86 秒），均为 CC0 循环 OGG。完整来源、原文件、日期、作者与署名说明在 `docs/ASSET_CREDITS.md`。用户提供图片没有误标成下载素材。

`AudioBus.play_event()` 保留原接口，别名映射 old enemy_hit/player_hit/combo_trigger 到 magic_hit/player_hurt/combo。玩家与敌人的施法声在真正放出魔法弹时触发，命中/受击声在撞击时触发，一题只结算和触发一次。最终胜利提示只用于 Boss 胜利。

音乐跨普通和精英战保持播放，换题不重启；Boss 切换专用曲目并淡入，入场与奖励降低音乐，标题/结算停止音乐。ESC 冻结音乐及战斗音效；暂停菜单点击仍可反馈。返回标题清理声音，退出先停止并释放。

轻量参数为 Master -1dB、SFX -9dB、BGM -25dB，可在 `audio_bus.gd` 修改。最多八个同时音效播放器，完成后自动释放；缺少音效或音乐时静默跳过。全部新增音频约 2.5MiB，不需要网络播放。

运行脚本自动隔离测试档案。以下命令已执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode import
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode smoke
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode artwork
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode av
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode capture -Resolution 1280x720
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode capture -Resolution 1920x1080
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run_v12.ps1 -Mode audit
```

最终结果：smoke `PASS | words=120 | failures=0`；立绘回归 `PASS | failures=0`；最终视听专项在无窗口及两种图形分辨率下 `PASS | failures=0`；确认退出和受保护文件审计成功，命令退出码 0。

图形测试使用 NVIDIA RTX 4070 SUPER / OpenGL 3.3 实际渲染。十二个音效解码均为非零、非削波样本；实际 SFX 总线捕获峰值约 0.36，确认调用进入有声混音。验证了普通曲持续、Boss 切换、换题不重播、暂停位置冻结、返回标题停止。

原回归继续覆盖完整四战与三次奖励、正确/错误重复点击、HP/Combo、六件强化、Boss 弱词、胜败统计、死亡、重开、返回标题、长期存档重读。专项覆盖正式图片比例、背景不重复、UI 遮挡、特效清理和缺失图/声音/音乐回退。

开发期间修正了 Boss 高度受容器留白限制、截图前积累静音导致音频捕获测试误报，以及有音乐后旧测试退出太快造成的音频线程清理提示。最终使用及时采集、明确停止和短暂释放等待完成验证。

## 已知问题与人工验收

没有发现未解决的功能阻塞。自动运行不等于完整人工试玩；尚未用人工连续游玩一整局并主观试听所有声音。普通音乐是 15.36 秒短循环，长期重复的疲劳程度、音效音量平衡与立绘自带发光边缘需要试玩确认。用户图片作者/许可未随文件提供，记录为用户提供，不自行宣称外部许可。

建议重点：Start Adventure → 答对看蓝金命中 → 答错看紫墨反击和释义 → 连答触发 Combo → 动画中 ESC 暂停/恢复 → 精英与 Boss 入场和音乐切换 → Boss 重考真实弱词 → 完成/失败报告 → 重启检查学习记录。另检查长单词、最长中文选项及窗口缩放的阅读舒适度。
