### 音量、循环与场景选择

- Godot原生解码采样16秒分布片段，检查非静音、时长、RMS与采样峰值，并从曲尾跨过循环点解码。
- 精英原OGG解码采样峰值约1.056，采用约 **-4.77dB资源播放补偿**；标题约 **-2.20dB**。书房/事件0dB。补偿后再叠加原场景安静增益和用户BGM总线设置；旧两首增益不改。
- 沿用一名Music播放器，0.2秒淡出→换流→0.4秒淡入；同曲安静/恢复0.25秒，缺曲淡出0.25秒。换流前明确停止旧播放，停止/退出时清除流引用，不新增叠播架构。
- 标题/地图→title_map；普通→原normal_battle；精英→elite_battle；Boss→原boss_battle；回忆/休息→memory_rest；事件/藏宝→event_special。书页/抄写员等阅读事件仍用书房分类；战斗奖励沿用该战斗曲并降低音量。
- 可选胜利分类回退title_map；失败报告用memory_rest。没有新增专用胜利曲。
- ESC暂停音乐位置与Tween；BGM/SFX独立百分比、0%静音、即时调整、自动保存保持，不重置用户配置。
- 缺曲仍用原Profiles.MUSIC候选顺序回退；未知/无候选时安全静音。

## 4. 怪物音效真正改善了什么

使用已持有且本轮重新核实CC0的两个资源包：[Kenney RPG Audio](https://kenney.nl/assets/rpg-audio)（Kenney Vleugels）和 [80 CC0 RPG SFX](https://opengameart.org/content/80-cc0-rpg-sfx)（rubberduck）。原包包含实际book/page、slime、fire、chain、creature与spell声音。

本轮新增以下18个WAV，不覆盖原21个：

| 家族 | 新文件 | 真实源片段 / 改善 |
| --- | --- | --- |
| 墨水 | ink_spray、ink_splash_texture、ink_surge_texture | slime_01/02/04湿黏片段；替换普通挥动/石击，形成喷射、溅墨和墨潮质感 |
| 纸书 | paper_rustle、paper_strike、paper_heavy | bookFlip3、bookPlace3、bookClose；翻页、书本拍击、重书合拢，替代通用魔法弹声音 |
| 魔典 | mimic_open_texture、mimic_bite_texture、mimic_drain、mimic_devour_texture | 开书、合书＋怪物声、spell_02吸取、怪物声＋合书；开合/撕咬/吸收/吞噬分开 |
| 幽灯 | wisp_fire、wisp_shift、wisp_flare | spell_fire_01/04/07；火焰释放、突袭与爆闪，替代玩家飞弹变调 |
| 档案官 | archive_chain_texture、archive_seal_texture、archive_judgment_texture | chain_01真实链声、法术＋锁、法术＋宝石；锁链/封印/仪式分开 |
| Boss | boss_tome_texture、boss_impact_texture | 开书＋蓄力法术、碎石＋火焰魔法重击；强化古书施法与重型命中 |

以上文件位于 `assets/audio/sfx/`，后缀均`.wav`。边注之灵复用纸页/墨蚀家族，尘页守卫复用纸书碰撞；53个家族事件使用新增片段，2个扑击释放事件保留原挥动音。没有增加事件名称来充数。

原生离线处理：裁前导静音，部分源按清单混合；单声道PCM16，0.09目标RMS/0.38峰值约束，3ms起音和25ms淡出。每个文件的作者、源列表、SHA256、处理增益与时长在 `v18_manifest.json` / `v18_sfx_manifest.json`。

原施法/命中动画调用点没有改变，仍各一次；实际HP损失才播玩家受击，护盾使用原挡伤事件。`TEXTURE_FALLBACKS` 使新素材缺失时优先回退旧声音，全部缺失时静默跳过。同名事件专用文件仍可优先覆盖家族素材。

**尚无专门纸张撕裂录音**，当前用翻页/重书片段改善纸书身份。湿黏片段是用于墨水表现的音色选取，不声称真实墨水录音。主观音色是否合适仍需人工听感验收。
