## 3. 七层地图与短局平衡

### 路线

第1层是“入口战斗”，包含书塔入口遭遇，不额外浪费一层空房。第2–6层每层有3个分支节点；第7层固定图书管理员。底层技术入口和报告各为一个内部节点，但不作为可游玩层显示。

**共7个可游玩层、17个可选房间、19个内部节点。** 不再显示第0层或第8层报告。所有节点连接向下一层，末层分支连接Boss。边缘路线也至少提供一条绕过精英的连接。

| 层数 | 生成池（顺序随机） |
| --- | --- |
| 1 | 入口普通战斗 |
| 2 | 普通 / 回忆 / 藏宝 |
| 3 | 普通 / 普通 / 休息 |
| 4 | 精英 / 普通 / 回忆 |
| 5 | 普通 / 藏宝 / 休息 |
| 6 | 精英 / 普通 / 普通 |
| 7 | 最终首领 |

每张地图从第3、5、6层普通节点中替换**1–2个问号节点**，同层最多一个。5种事件仍按原种子机制抽取。普通敌人池的阶段改为1–2层、3–4层、5–6层，确保尘页守卫及拟态魔典仍能在七层出现；精英二选一、Boss固定，原防止连续三场同种规则保留。

### HP

短局HP集中在`scripts/short_run_balance.gd`，未覆盖原敌人定义表。生成HP为：

`ceil(短局基础HP × 难度HP系数) + (当前层 - 1) × 成长`

| 怪物 | V1.8基础HP | V1.9短局基础HP |
| --- | ---: | ---: |
| 墨影 | 50 | 46 |
| 尘页守卫 | 50 | 48 |
| 纸页傀儡 | 60 | 52 |
| 拟态魔典 | 52 | 48 |
| 幽灯之灵 | 44 | 42 |
| 边注之灵 | 70 | 68 |
| 沉默档案官 | 75 | 72 |
| 遗忘图书管理员 | 100 | 90 |

成长从所有敌人每层+14，改为普通**每层+1**、精英/Boss**每层+2**。第7层Boss HP分别为简单93、普通102、困难116；攻击力与难度攻击系数未改，Boss二阶段与蓄势阈值未改。

普通难度无遗物、全对仅用飞弹的参考检查：第6层五种普通怪均5题；第4层边注6题、档案官7题；第7层Boss8题。爆发和遗物可进一步缩短。困难或答错会更长，没有按题数强制结束战斗。

奖励仍为普通胜利1次、精英2次、藏宝1次；18遗物+3补给的抽取规则不变。普通胜利基础恢复5生命、精英8生命、休息20%最大生命均保留。不同路线通常可以得到约1–8次强化选择，事件可能提供额外收益。没有删除低频遗物以缩小资源池。

三档重点样例中，100%与目标80%答对的合法七层路线均通关；答题20–38次、遗物6–7件。80%样例普通剩69生命、困难剩51生命。随机遗物会影响结果，这些是样例而不是全种子平衡保证，更不是真人时长。

## 11. 当前限制与人工验收

- **7–10分钟、难度与奖励组合手感仍需真人计时。**6个自动流程是重点样例，不能代表所有随机奖励/失误率。
- 新主角蓝焰/碎页边缘、面部清晰度、施法起点与角色视觉大小，请在实际显示器上确认；透明处理未覆盖用户源图。
- 当前无关闭后续同一局功能，标题没有续局按钮；长期学习自动保留。没有新增存档格式。
- 尘页守卫独立PNG仍缺，使用原墨影回退；专用胜利曲仍缺，继续标题曲回退。这两项是继承的资源限制。
