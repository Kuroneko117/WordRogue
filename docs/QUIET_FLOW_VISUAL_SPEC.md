# 克制扉页风格：全流程统一规范

2026-10-26。依据：用户认可当前标题页风格，指出与旧游戏页面割裂，要求修正统一性。本轮在已选方向上实施，不继续生成新的整屏概念图。

## 唯一视觉基准

`docs/title_frontispiece_review/title_1280x720.png` 是本轮基准。旧 `battle_ui_target.png` 和 2026-10-23 皮革/金框实施记录作为历史保留，不再作为此次表面的样式来源。

- 墨蓝 #10191d；界面暗纸 #152024；纸白 #dfd8c8；旧铜 #be9a74；次级灰 #a5b0b0。
- 语义青灰蓝 #8caeb6；威胁与错误 #cb8b89；正确用柔绿，满蓄势保留清晰红色警示。
- 中文标题沿用宋体/衬线与现有字体回退，正文使用现有打包 Noto Sans SC，英文单词用拉丁衬线；不下载或分发系统字体。
- 大面积留白与单侧书脊线是共同装帧语言；去除旧的重复金色角饰、圆圈封印、亮纸卷轴、皮革纹理和持续发光边框。
- 交互使用小箭头、短下划线、轻微明暗变化。禁用有灰色文字和真实不可点击状态；选中、正确、错误有语义文字与线条反馈。

## 页面职责

| 页面 | 排版与重点 |
| --- | --- |
| 标题 | 保留已认可构图、背景渐隐、字标和无框菜单 |
| 难度 | 三个试炼栏，静默编号、推荐文字和明确入口 |
| 地图 | 图标、路径和节点状态为主，去除背景星图圈；行囊为安静附页 |
| 战斗 | 保留左右立绘与中间答题；暗纸单词、细线选项、小型法术图标；红色警示不削弱 |
| 奖励 | 保留真实三选一，统一小墨印、标题与正文，去除皮革与亮纸框 |
| 事件 / 书房 / 休息 | 共用暗色扉页、留白和清晰成本/生命说明，保持原交互 |
| 暂停 / 设置 / 确认 | 暗色章节页、原生无框菜单、细轨道与小滑块，保持静音/保存机制 |
| 报告 | 安静的摘要与两列词单，长列表独立滚动，重新游玩和返回清楚 |

不同页面可以因信息密度而有不同布局，统一的是字体、色彩、明暗、线条和交互语法。不会用一种整屏贴图覆盖所有交互。

## 资源与背景

继续使用已认可的场景背景与角色原图，不改写图片、不重新生成立绘，不下载素材。新版标题保留长廊构图，地图恢复原主图书馆背景；普通战为长廊，精英为精英场景，Boss 为主图书馆，回忆/休息为书房，事件/藏宝为祭坛。背景使用共同明暗处理，但不删除场景或将场景全部替换成同一张图；运行中的攻击、投射物和伤害反馈保持原机制。UI 小型法术图标由可编辑的原生线条绘制。
