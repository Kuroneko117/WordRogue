# 遗忘书塔 UI 实机审查与视觉方向

日期：2026-10-16。Godot 4.7.2，现有 V1.9 工程；不改玩法。

## 已观察的问题

- 运行现有 tests/v19_ui.gd，实际生成并查看 1280×720 标题截图。标题被大面积不透明圆角面板包住，背景图书馆的纵深消失，按钮缺乏材质和主次。
- UI 主要由相同的圆角 PanelContainer 与 Button 构成；答题、奖励、事件和报告没有不同的书塔语义。
- 字体以同一无衬线字体为主，标题、正文和数字缺乏区分。
- 地图图标已具有语义，不能推翻已可玩的分支与状态；应加入章节标记和塔层结构。
- 原 UI 基线检查 1616 项，3 项失败：战斗底部统计/意图说明超过 1080 参考画布。沙盒另有 Windows 证书读取错误；不代表游戏联网。
- 现有施法、投射物、命中、蓄势和暂停逻辑已经完整，应沿用，仅升级界面材质和反馈。

## 本轮采用的视觉系统

- 名称：墨金藏书。深靛墨底、暖纸文字、旧金细框，蓝色为玩家、暗红为威胁。
- 形状：书脊、切角页签、双层线框、符文封印；少量矩形保留给阅读区，不使用玻璃或大面积渐变。
- 字体：书卷标题采用系统宋体/衬线字体并保留打包字体回退；正文保持现有中文字体，状态数字用清晰的英文衬线/现有回退。
- 图标与材质：自绘线性矢量，保留当前正式立绘和背景，不下载替换角色。
- 动效：120–240ms，悬停和聚焦共用强调；按钮缩放只作用于视觉，退出时恢复；屏幕入场淡入，不更改答题结算时序。
- 关键留白：左右立绘通道、中央题目与答案通道、底部意图区分开；装饰不拦鼠标，不覆盖蓄势与弹体。
