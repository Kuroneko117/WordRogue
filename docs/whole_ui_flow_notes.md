## 文件

- `scripts/ui/flow_folio.gd`：原生章节徽记、分隔纹、可重用安全内容边距、由内联原创 SVG 创建的菱形滑块。没有外部下载或付费调用。
- `scripts/ui/route_view.gd`：地图章节页眉、星图/圆规刻度、分段路线与明暗路径、图例和附页行囊。原节点字典、路径、可进入状态、操作和收益均保留。
- `scripts/ui/map_icon.gd`：节点内外环、方位刻度、可进入菱形刻印；原类型、状态和焦点轮廓保留。
- `scripts/ui/event_view.gd`：事件书页双栏，章节号、正文、提示、生命代价和行动分区；选择、问题、结果各状态完整保留。
- `scripts/ui/review_view.gd`：回忆双页，左附页为规则/恢复/进度/生命，右页为动态单词和四选一。英文采用现有 ArchiveNumber 字体。
- `scripts/ui/pause_menu.gd`：章节书签菜单；音乐/音效两组独立刻度滑轨、动态百分比或“已静音”文字；原创菱形抓手；原即时保存、试听、默认、确认退出、ESC和焦点恢复保留。
