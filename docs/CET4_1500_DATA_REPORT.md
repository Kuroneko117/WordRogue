### 可复现选择方法

1. 仅接受 `tag` 含独立 `cet4` 标记的词条；不是从非四级数据中凑数。
2. 小写归一化，保留2～22个英文字母的单词；排除短语、格式项和明确的屈折变体。
3. 要求有音标、中文译义、可读的题目释义；去除领域括号等格式残留，排除乱码、HTML和过长展示文本。
4. 首选正数 `frq`（当代语料词频，数值越小越常用）升序；若无frq则使用BNC并排在有frq的条目之后；同排名按词形稳定排序。
5. 从3681个可用候选中取排名最靠前的1500个，实际全部有frq，范围137～2857，没有用到BNC回退；不是字母前1500，也不是随机1500。
6. 整理为一条主要词性、最多两项简明中文义；对抽样和显示检查发现的条目使用显式修订表。原完整多义数据保留为 `source_translation`，支持复核与保守干扰项过滤。
7. 统一重音、长音和部分旧音标字形；conduct与graduate按选用词性专门修正。音标仍保留源数据的英式/传统记法与可能的异读，不宣称做过逐词语音专家审核。

整理脚本：`tools/build_cet4_core.py`，只供开发整理；游戏运行使用本地 JSON 和 GDScript，不依赖Python、网络或后端。

## 判题和干扰项规则

- 每个单词当前使用 `meaning` 显示的主要义项；选项附词性，战斗词卡也标明当前词性。答题通过选项索引判断，不要求玩家输入某一种中文措辞。
- 相同译义不可在同题重复；一个单词全部源释义的中文词义片段与候选存在重叠时，排除该候选。
- 加入常见中文等价组，如保持/维持/保留、购买/买、帮助/协助/援助等；同时排除明显包含关系。三个错误选项之间也检查冲突。
- 困难档在安全候选中优先相同词性、同主题和接近的译义长度，形成更接近的干扰项。主题依据中文释义中的教育、人物、身体、情感、金钱等关键词作粗分类；没有引入CET-6或限时答题。当前并非完整语义相似度模型，未声称每题都有专业设计的近义干扰项；未知主题按词性和长度退化。
- 书房、事件与战斗使用同一套题目生成器，避免复习题绕过歧义检查。
- 普通难度词库读坏或条数不符时拒绝启动该档并显示错误，不偷偷用120词冒充1500词。简单难度仍能使用原词库。

## 抽样记录与限制

逐项记录：`docs/CET4_1500_REVIEW.md`；完整样本字段：`docs/CET4_1500_REVIEW_SAMPLE.json`。

审核由开发助手逐项阅读并修订，不是人类教师签核；没有声称人类已审核1500条。自动检查可以验证结构、去重、已知等价与选项生成，无法数学证明所有多义词、近义词和语境下绝无语义争议。未发现的词义或音标问题仍应通过实际学习反馈继续修订。

使用稳定的单词标识保持Mastery：切换词库不会删除旧词进度；未在当前1500中选入的旧词仍保留记录。新增词仍按原50起始、答对+5、答错−10、0～100封顶的规则处理。
